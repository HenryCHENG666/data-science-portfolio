# Shichuan Cheng — Data Science Portfolio

Live site: https://HenryCHENG666.github.io/data-science-portfolio/

Project: https://github.com/HenryCHENG666/data-science-project

University of Macau · MSc Data Science (Precision Medicine) · CISC7204 Practice 09.

The site is published with GitHub Pages from **main / (root)**. `index.md` is the entry point. `assets/` contains original SVG analysis figures, CSS, an accessible JavaScript response explorer and synthetic summary data. No external scripts, tracking or secrets are used.

The showcase is a completed educational prototype, not a biologically validated cell model. The README in the project repository contains data permissions, findings, assumptions, one-command reproduction instructions and limitations.

## Update the site

Regenerate figures in the project repository, copy the desired SVGs and `results/summary.json` mean effects to `assets/`, update the displayed findings and commit. Pages rebuilds from the branch automatically. The explorer currently embeds the seven familiar-dose mean-effect rows in `assets/explorer.js`; keep those synchronized with `assets/effects.json` when changing results.
